# AMARILLOU Live Control v0.7.1

Atualização pequena para facilitar o acesso ao modo local.

- Link **Baixar modo local** no menu lateral, apontando para as releases do GitHub.
- Links para o ZIP da ferramenta (via releases) e para o download oficial do Node.js nas instruções de Presets, Conexão & dados e guia de uso.
- Instruções para abrir Assets, baixar o ZIP completo, extrair e executar INICIAR-LOCAL.bat.
- Identificação da versão atualizada para v0.7.1.

Sem alterações na lógica dos macros, rankings, pontuação ou armazenamento. Esquema de dados permanece 6, compatível com v0.7.

Online: substitua index.html, overlay.html e GUIA.html. Local: feche a ponte, extraia o pacote completo e execute INICIAR-LOCAL.bat. Não precisa reinstalar o Node se já funciona.

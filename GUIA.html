AMARILLOU LIVE · VERSÃO 0.2

Do projeto à sua live.

Esta pasta contém o site completo e uma ponte local opcional para os overlays. Você não precisa compilar o projeto.

Antes de transmitir: teste um like, um presente e um combo na sua instalação do TikFinity. A contagem e a comunicação foram testadas com eventos simulados. O teste real no seu OBS/Live Studio ainda precisa ser feito.

Atualizar da versão 0.1 para 0.2

Substitua index.html e overlay.html e envie também GUIA.html na mesma pasta publicada no GitHub. Aguarde a publicação e pressione Ctrl+F5. Confira v0.2 no painel e clique em Experimentar demo, mesmo sem live. Não precisa apagar seus dados ou alterar seu domínio.

1. Colocar no GitHub Pages

  1. Extraia o ZIP. Abra a pasta amarillou-live.
  2. No GitHub, crie um repositório chamado amarillou-live.
  3. Em Add file → Upload files, envie os arquivos e pastas de dentro da pasta extraída. O index.html precisa ficar direto na raiz do repositório.
  4. Confirme o envio em Commit changes.
  5. Abra Settings → Pages. Escolha Deploy from a branch, branch main, pasta / (root), e salve.
  6. Espere a publicação e abra o endereço mostrado pelo GitHub.

Para seu usuário, usando esse nome de repositório, o endereço será https://xamarilloux.github.io/amarillou-live/. O endereço final indicado pelo GitHub é o correto caso exista domínio personalizado.

2. Primeiro contato com o painel

  1. Clique Experimentar demo para conhecer os cartões sem mudar seu histórico.
  2. Saia da demonstração. Abra o TikFinity Desktop e conecte-o à live.
  3. Em Conexão & dados, confira ws://localhost:21213/ e defina o fuso antes de receber eventos.
  4. Clique Conectar TikFinity. Se surgir permissão de acesso local/rede, autorize o seu site.
  5. Envie um like ou comentário e confira o diagnóstico. Estar conectado ao WebSocket não significa que a live esteja transmitindo eventos.

Se a conexão online for bloqueada, use o modo local abaixo. Não precisa desativar a segurança do navegador.

3. Overlays no OBS: modo local

O navegador e o OBS não compartilham o mesmo save. A ponte local permite que todos vejam o mesmo histórico e que os cartões sejam alterados pelo painel.

  1. Instale Node.js, versão 22.15 ou superior.
  2. Na pasta extraída, abra INICIAR-LOCAL.bat. Deixe a janela aberta.
  3. Abra http://127.0.0.1:8787/ no navegador. O topo deve indicar MODO LOCAL · OBS.
  4. Se já tem histórico online, exporte um backup lá, desconecte o painel online e restaure o arquivo neste painel local.
  5. Conecte ao TikFinity. Escolha o ranking ou cartão desejado e clique Copiar link do overlay.
  6. No OBS, adicione uma fonte Navegador. Cole o link no campo URL. Deixe Arquivo local desmarcado.
OverlayTamanho inicial
Ranking Top 5640 × 900

Ajuste altura para Top 10 (por exemplo, 1300 px). Os overlays são transparentes; o quadriculado existe só na prévia do painel. Um aviso aparece se a fonte perder a conexão. Cada link fixa o período/métrica selecionado; copiar outro link permite criar outra fonte.

O servidor continua coletando quando a aba do painel fecha. Ao reiniciar a ponte, conecte novamente pelo painel. Os links de overlay permanecem os mesmos.

4. Herói e vilão

  1. Digite o @ no campo do lado desejado e salve.
  2. Se o participante já foi identificado nos eventos, a foto/nome aparecem. Se ainda não foi, o cartão aguarda.
  3. Para escolher a foto manualmente, abra Nome e foto manuais, informe uma URL pública de imagem e salve.
  4. Copie o link individual ou da dupla. Alterações no painel local atualizam o OBS.

Não existe busca automática de qualquer perfil do TikTok só pelo @ nesta versão. Limpe os campos manuais para voltar a usar as informações da live.

5. O que os números significam

  • Likes / tap taps: mesma métrica, atribuída ao participante que o TikFinity informar.
  • Moedas: valor unitário do presente multiplicado pela quantidade, não o saldo de pontos nativo nem o pagamento do criador.
  • Semana: segunda a domingo. Mês é o mês do calendário, e dia vira à meia-noite do fuso definido.
  • Combo recente: última sequência com mais de uma unidade. Maior combo é o recorde de quantidade de hoje.
  • Mais caro: maior valor de uma unidade hoje; não o maior valor total de um combo.

6. Guardar seu histórico

No modo web, os dados ficam neste navegador. No modo local, ficam em %USERPROFILE%\.amarillou-live\state.json no Windows. Exporte backups frequentes pela aba Conexão & dados. Restaurar substitui todo o histórico e exige desconectar primeiro.

Não publique backups, state.json ou keys.json no GitHub. O projeto entregue não inclui dados reais nem chaves. Eventos anteriores à coleta ou perdidos durante desconexões não são recuperados.

7. TikTok Live Studio

Teste o mesmo link local caso sua versão permita uma fonte de link/navegador. A compatibilidade com o Live Studio real ainda precisa de validação. No seu fluxo com câmera virtual, você também pode montar os overlays no OBS e enviar a cena ao Live Studio.

Se algo não funcionar

  • Não conecta: confira o TikFinity no mesmo PC, live conectada, API WebSocket ativa e endereço correto.
  • Site online bloqueado: confira permissões locais ou use o modo local. HTTPS e WS podem variar entre navegadores.
  • Overlay vazio no OBS: copie o link pelo painel que indica MODO LOCAL; mantenha INICIAR-LOCAL aberto; não use o link do modo web esperando que ele compartilhe o save do Chrome.
  • Não há foto: aguarde uma interação do participante ou informe uma URL de foto manual. URLs antigas podem expirar.
  • Moedas zeradas apesar de presentes: confira “Presentes sem valor” no diagnóstico; o formato da sua versão pode exigir ajuste do adaptador.
  • Endereço em uso: já existe uma ponte em execução ou outro programa ocupa a porta 8787.

Detalhes de arquitetura, limites e validação estão no README e nos arquivos da pasta docs.

Abra o TikFinity no mesmo computador e conecte-o à sua live.

Histórico & backup

Aguardando…

Restaurar substitui todo o histórico. Exporte uma cópia antes. Não publique backups no GitHub.

OBS & Live Studio

Para compartilhar o mesmo histórico entre aplicativos, use o modo local incluído no projeto.

  1. Instale Node.js 22.15 ou superior.
  2. Abra INICIAR-LOCAL.bat.
  3. Acesse http://127.0.0.1:8787.
  4. Conecte, copie o overlay e cole na fonte de navegador.

É o mesmo web app. A ponte mantém uma conexão com o TikFinity e salva no computador. Não precisa compilar nem instalar pacotes. O modo online e o local têm históricos separados; use o backup para migrar.

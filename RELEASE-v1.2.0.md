# v1.2.0 — Meta de Baú, macros individuais e rankings verticais

## Novidades
- Nova aba **Meta de Baú**: planejamento financeiro editável, contador por moedas de presentes, baús disponíveis, registro manual de liberação, controles de pausa/ajustes/resets, estatísticas, histórico diário, simulador e tabela comparativa.
- Overlay do baú com preview, progresso, baús conquistados ainda disponíveis, personalização e atualização pelo mesmo link. Canvas 800 × 600.
- Caixa **Ativo** em cada macro: desligue uma ação sem parar o preset. Pendentes daquele macro são retirados; demais ações continuam.
- Rankings com escolha **Vertical (uma coluna)** ou **Horizontal (duas colunas)**. Vertical é o padrão; rankings de presentes permitem Top 1, 3, 5 ou 10.
- Correção do desalinhamento das fotos em rankings sem fundo.

## Como atualizar
Feche o serviço anterior. Use o novo .EXE em `EXECUTAVEL-WINDOWS`. Para atualizar o GitHub Pages, envie o conteúdo de `CODIGO-FONTE` à raiz publicada do repositório. Copie novos links dos rankings depois de selecionar a disposição desejada.

Dados antigos são preservados. Macros antigos começam marcados e a Meta de Baú começa vazia. Exportações de presets usam formato 4, com importação dos formatos anteriores. Não use novos presets/dados com versões antigas que não reconhecem os novos campos.

A ferramenta não cria nem compra baús no TikTok. Conversões são estimativas configuradas pelo streamer. O executável continua portátil com terminal e Node.js incluído.

## Verificação
